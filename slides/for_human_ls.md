# 薬局における掲示・掲載要件一覧
## 法令・制度順守のためのチェックリスト

---

## 掲示・掲載要件の全体像

- 薬局の運営において義務付けられている、または推奨される情報開示
- 主に以下の3つの場所での対応が必要
  - **薬局内 (内側):** 患者が来局時に確認できる場所
  - **薬局外 (外側):** 薬局の外から確認できる場所
  - **ウェブサイト (WEB):** インターネット上で公開する情報
- 一部の要件は未対応の場合、加算の返還リスクが存在

---

## 基本的な必須掲示要件

### 薬局開設許可証
- **該当要件:** 全ての保険薬局
- **掲載場所:** 内側 (必須)
- **備考:** 薬局内の見やすい場所

### 保険薬局である旨の表示
- **該当要件:** 全ての保険薬局
- **掲載場所:** 内側 (必須), 外側 (必須)
- **備考:** 薬局の見やすい場所（内or外）

---

### 調剤報酬点数表
- **該当要件:** 全ての保険薬局
- **掲載場所:** 内側 (必須), WEB (原則必須)
- **備考:** 原則ウェブサイトにも掲載

### 個人情報保護方針
- **該当要件:** 全ての保険薬局
- **掲載場所:** 内側 (必須)
- **備考:** なし

### 薬剤師不在時間
- **該当要件:** 薬剤師不在になる場合
- **掲載場所:** 内側 (必須), 外側 (必須)
- **備考:** なし

---

## 地域連携・加算関連の掲示 (1)

### 在宅患者訪問薬剤管理指導を行う薬局である旨
- **該当要件:** 地域支援体制加算等
- **掲載場所:** 内側 (必須), 外側 (必須)
- **備考:** なし

### 近隣及び自局の連絡先電話番号等
- **該当要件:** 地域支援体制加算等
- **掲載場所:** 外側 (必須)
- **備考:** なし

### 後発医薬品の調剤を積極的に行っている旨
- **該当要件:** 後発医薬品調剤体制加算
- **掲載場所:** 内側 (必須), 外側 (必須)
- **備考:** なし

---

## 地域連携・加算関連の掲示 (2)

### 開局時間 / 対象となる日及び受付時間
- **該当要件:** 夜間・休日等加算
- **掲載場所:** 内側 (必須), 外側 (必須)
- **備考:** 外側は開局時間のみ

### バイオ後続品の調剤を積極的に行っている旨
- **該当要件:** バイオ後続品調剤体制加算
- **掲載場所:** 内側 (必須), 外側 (必須)
- **備考:** なし

---

## 運営規程・DX推進関連の掲載

### 運営規程、重要事項等
- **該当要件:** 居宅療養管理指導
- **掲載場所:** 内側 (必須), WEB (原則必須)
- **備考:** 原則ウェブサイトに掲載

### 医療DX推進の体制・情報活用
- **該当要件:** 電子的調剤情報連携体制整備加算
- **掲載場所:** 内側 (必須), WEB (原則必須)
- **備考:** 原則ウェブサイトに掲載

### 費用徴収等（長期収載品の選定療養など）
- **該当要件:** 長期収載品の調剤
- **掲載場所:** 内側 (必須), WEB (原則必須)
- **備考:** 原則ウェブサイトに掲載

---

## 【最重要】災害・新興感染症発生時の対応体制

### 災害・新興感染症発生時の対応体制
- **該当要件:** 連携強化加算
- **掲載場所:** WEB (重要)
- **備考:** **【重要】未掲載は個別指導で自主返還リスクあり**
