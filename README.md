### 備考・注釈（自動脚注エリア）
[^1]: 薬局内の見やすい場所に掲示すること。
[^2]: 薬局の見やすい場所（内側または外側）に掲示すること。
[^3]: 原則としてウェブサイトにも掲載すること。投薬カウンター等の指導時に患者が分かりやすい場所に掲示する。
[^4]: 不在のため調剤に応じることができない旨、不在理由、帰局時刻を記載すること。
[^5]: 居宅療養管理指導を実施する場合に必要。原則としてウェブサイトに掲載すること。
[^6]: 原則ウェブサイトへの掲載が必須。オンライン資格確認等により取得した情報を活用して調剤等を行う体制について明記すること。
[^7]: **【重要：自主返還リスク】** 災害や新興感染症の発生時等における対応体制をウェブサイトで広く周知することが算定要件。行政や薬剤師会のページへのリンクのみは不可。未掲載の場合は要件不備となる。
[^8]: 長期収載品（先発医薬品）の処方等又は調剤に係る費用徴収その他必要な事項について、原則ウェブサイトに掲載すること。
[^9]: 水薬瓶、軟膏壺の容器代などの実費徴収を行う場合に必要。
