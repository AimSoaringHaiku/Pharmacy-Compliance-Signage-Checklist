# 📋 薬局Webサイト監査：重要資料および法的根拠の解説

本ドキュメントは、令和8年度の最新調剤報酬改定に基づく、当社薬局Webサイトの監査結果と法的根拠（リスク）をまとめた内部資料です。

## 📊 資料①：「加算取得状況マトリックス表」の解説
全45店舗の現在の加算届出状況を一覧化したデータです。

* **最大のリスク要素：連携強化加算（36店舗算定）**
  * 災害や新興感染症発生時の具体的な対応体制を、自社Webサイトに掲載することが**必須要件**となっています。
  * ※行政や薬剤師会のページへのリンクのみを貼る対応は**不可（要件違反）**となります。
* **現状の課題と危険性**
  * 現在、対象となる**すべての店舗（36店舗）で未掲載**となっています。
  * 未掲載のまま算定を継続すると「要件不備」とみなされ、個別指導などで**過去に遡って自主返還（返戻）を求められる重大な懸念**があります。

## 🔍 資料②：「掲示物コンプライアンス チェックシート」の解説
最新の調剤報酬改定に基づき、薬局の掲示物要件をまとめたチェックシートのエビデンスです。

* **注目ポイント：『WEB』の列**
  * 法改正により、これまでの「店舗の壁に貼るだけ」の運用から、**Webサイト上への掲載が必須化**されました。
  * 掲載区分が**「◎（算定要件・必須）」**または**「〇（原則義務）」**となっている項目が大幅に増加しています。
* **今回のWebサイト改修の目的**
  * 単なる見た目のリニューアルや見栄えの改善ではありません。
  * 国が定めた最新のコンプライアンス（法的義務）を満たし、**店舗の減収リスクをゼロにするための必須の防衛措置**となります。
