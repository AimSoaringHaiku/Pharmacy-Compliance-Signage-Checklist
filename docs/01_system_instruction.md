# 【作業依頼】全45店舗Webサイトのコンプライアンス適合に伴う一括更新

システムご担当者様 （CC：関係者の皆様）
お疲れ様です。〇〇です。

令和8年度調剤報酬改定に基づく、当社薬局Webサイトの掲載義務要件の調査を実施しました。
その結果、「連携強化加算」および「電子的調剤情報連携体制整備加算（医療DX）」のWeb掲載要件において、修正検討案が見つかりました。特に「連携強化加算」における災害等対応体制については、個別指導等において過去に遡っての自主返還（返戻）を求められる懸念もあるようです。

最新の法令に適合した「追加用HTMLデータ」を準備しました。
お手数ですが、共有のデータを用いて、各店舗のWebサイト（特記事項や医療DXのエリア等）へテキストの一括更新（流し込み・マージ作業）をお願いいたします。

# 【別紙】修正文言提案書：全45店舗分

今回のWebサイト更新は、以下の2パターンに分かれます。
該当する店舗IDのページに、指定のHTMLテキストを追加・上書きしてください。

## 【パターンA】連携強化加算 ＋ 医療DX加算 を追加する店舗（36店舗）
**▼ 対象店舗ID**
`kohoku`, `kohoku2`, `machiya`, `minamisenju`, `azusawa`, `itabashi`, `oyama`, `kamijujo`, `nakazato`, `nishigahara`, `oimachi`, `oimachi2`, `gotanda`, `gotandaekimae`, `togoshiginza`, `ushigome`, `kawadacho`, `shinwakamatsucho`, `nishishinjuku`, `wakamatsukawadaekimae`, `akihabara`, `shinokachimachi`, `tsukiji`, `iidabashi`, `komagome`, `nezu`, `onarimon2`, `toranomon`, `toranomon2`, `hiroo`, `mita`, `mishuku`, `chofu`, `hibarigaoka`, `yagisawa`, `tachikawa`

**▼ 上記36店舗に追加（マージ）するHTMLテキスト**
```html
<h3>災害や新興感染症発生時における対応体制（連携強化加算）</h3>
<p>当薬局は、都道府県知事から「第二種協定指定医療機関」の指定を受けており、災害や新興感染症の発生時等において対応可能な体制を確保しています。</p>
<ul>
<li>自治体等からの要請に応じて、自宅療養者等に対する調剤、オンライン又は訪問による服薬指導、および薬剤の交付（配達等）を行う体制を整備しています。</li>
<li>新型コロナウイルス等の抗原検査キットや、感染対策に必要な衛生材料等を提供できる体制を整えています。</li>
</ul>

<h3>電子的調剤情報連携体制について</h3>
<p>当薬局では、医療DXを推進し質の高い医療を提供するため、以下の体制を整備しています。</p>
<ul>
<li>オンライン資格確認システム等を通じて患者様の診療情報・薬剤情報等を取得し、調剤・服薬指導に活用しています。</li>
<li>マイナ保険証の利用促進など、医療DXを通じた情報取得・活用に取り組んでいます。</li>
<li>電子処方せんの受付や、電子カルテ情報共有サービス（今後導入予定）を活用する体制を整えています。</li>
</ul>
```
